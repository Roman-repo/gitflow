Обработка "Групповая обработка захваченных объектов"

Вариант работы Захват

Позволяет захватить правила с отбором по Конвертации и по виду правил

Вариант работы Отмена захвата

Позволяет отобрать захваченные объекты по одному или нескольким критериям:
  • Конвертация
  • Пользователь
  • Период захвата
С отобранными объектами можно выполнить одно из следующих действий:
  • Отменить захват с откатом изменений
  • Снять захват
