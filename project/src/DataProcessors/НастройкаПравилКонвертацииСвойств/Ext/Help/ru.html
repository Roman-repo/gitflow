Обработка "Настройка правил конвертации свойств"

Предназначена для сопоставления свойств конфигураций или конфигурации и объекта формата для правила конвертации объекта.
Можно выбрать вариант отображения свойств (все, не сопоставленные, сопоставленные).
Можно выполнить автоматическое сопоставление не сопоставленных свойств. Свойства простых типов сопоставляются по наименованию. Свойства ссылочных типов сопоставляются по типу значения.
При необходимости свойства можно сопоставить вручную, выбрав требуемое свойство в соответствующем столбце.
Для переноса результата сопоставления в правило конвертации объекта следует использовать кнопку Создать правила конвертации свойств.
