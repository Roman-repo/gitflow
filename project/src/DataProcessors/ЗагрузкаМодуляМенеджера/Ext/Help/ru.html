Обработка "Загрузка конвертации XDTO"

Выполняет загрузку правил и обработчиков из модуля синхронизации через универсальный формат. Загрузка может производиться как в существующую конвертацию, так и в новую. При загрузке в новую конвертацию есть возможность загрузить структуру метаданных.

Загрузка правил в новую конвертацию

Для загрузки правил в новую конвертацию на этапе "Выбрать конвертацию для загрузки" следует указать вариант "Новая". При необходимости можно заполнить название новой конвертации.

Конфигурация при этом может быть выбрана существующая, либо указан вариант загрузки новой конфигурации.

На следующем шаге "Настроить источник загрузки" следует выбрать источник данных:

  • Выгрузка конфигурации в файлы XML. Следует указать путь к каталогу, в который были выгружены файлы из Конфигуратора (меню Выгрузить конфигурацию в файлы)
  • Каталог проекта EDT. Следует указать файл project базы, развернутой в среде 1С-EDT.
При загрузке из каталога файлов XML или каталога проектов EDT необходимо указать имя общего модуля, в котором хранятся правила конвертации через универсальный формат (например, МенеджерОбменаЧерезУниверсальныйФормат).
Если выбран вариант использования существующей конфигурации, также можно использовать следующие источники данных:
  • Буфер обмена. Загрузка производится из модуля, предварительно скопированного в буфер обмена
  • Текстовый файл. Загрузка производится из модуля, предварительно сохраненного в текстовый файл. Следует указать путь к файлу в поле Каталог.
После выбора источника данных следует нажать на гиперссылку "Загрузить правила конвертации".
При этом будет выполнена загрузка структуры метаданных (если это было указано) и загрузка правил конвертации в новую конвертацию.
Если при загрузке возникали ошибки, их можно увидеть по гиперссылке "Показать ошибки загрузки".

Загрузка правил в существующую конвертацию

Для загрузки правил в существующую конвертацию на этапе "Выбрать конвертацию для загрузки" следует указать вариант "Существующая" и выбрать конвертацию. 
Если при загрузке необходимо видеть состав изменений в правилах, следует установить флаг "Показывать расхождения в правилах".
Внимание: Если включен режим отображения расхождений в правилах, загрузка правил будет занимать более продолжительное время.
Если при загрузке необходимо обновить метаданные существующей конфигурации, следует установить флаг "Обновлять метаданные существующей конфигурации".

На следующем шаге "Настроить источник загрузки" следует выбрать источник данных:

  • Выгрузка конфигурации в файлы XML. Следует указать путь к каталогу, в который были выгружены файлы из Конфигуратора (меню Выгрузить конфигурацию в файлы)
  • Каталог проекта EDT. Следует указать файл project базы, развернутой в среде 1С-EDT.
  • Буфер обмена. Вариант возможен, если в конвертации не используется режим разделения модуля. Загрузка производится из модуля, предварительно скопированного в буфер обмена
  • Текстовый файл. Вариант возможен, если в конвертации не используется режим разделения модуля. Загрузка производится из модуля, предварительно сохраненного в текстовый файл. Следует указать путь к файлу в поле Каталог.
При загрузке из файлов XML или каталога проектов EDT необходимо указать имя общего модуля, в котором хранятся правила конвертации через универсальный формат (например, МенеджерОбменаЧерезУниверсальныйФормат).

Загрузка в режиме отображения расхождений в правилах

Если на шаге "Выбрать конвертацию для загрузки" был выбран режим отображения расхождений в правилах, на следующем шаге следует нажать на гиперссылку "Посмотреть расхождения и выбрать загружаемые правила". На данном этапе происходит анализ различий между исходными правилами и загружаемыми. Найденные расхождения отображаются в дереве значений.
Посмотреть различия можно с помощью соответствующей кнопки на командной панели.
В колонке "Принадлежность" можно увидеть, является ли правило обособленным (принадлежит только одной конвертации), либо разделенным (принадлежит нескольким конвертациям).
При необходимости можно изменить режим загрузки для разделенных правил: обновлять правило для всех конвертаций, либо обособить правило и изменить только текущую загружаемую конвертацию.
С помощью флажков следует отметить те правила, которые необходимо обновить.
Загружаемые различия можно сохранить в файл с помощью кнопки Еще - Сохранить список. Различия будут сохранены в архив, в котором находятся исходный и новый текст обновляемых правил.
После выбора правил, которые подлежат обновлению, необходимо нажать кнопку Готово. На этом этапе правила в исходной конфигурации еще не подвергаются изменениям.
Для загрузки выбранных правил следует нажать гиперссылку "Загрузить правила конвертации".

Загрузка в режиме без отображения расхождений в правилах

В данном режиме гиперссылка "Посмотреть расхождения и выбрать загружаемые правила" недоступна, следует нажать на гиперссылку "Загрузить правила конвертации". При этом будет выполнена загрузка правил в существующую конфигурацию. Если при загрузке возникали ошибки, их можно увидеть по гиперссылке "Показать ошибки загрузки".

Загрузка правил при использовании совместной работы

Если в информационной базе включен режим совместной работы, при загрузке правил применяются следующие ограничения:
Обновляются правила, которые не захвачены либо захвачены текущим пользователем запустившим загрузку
Если загружаемое правило захвачено другим пользователем, оно не может быть обновлено. О наличии таких правил будут выведены ошибки (гиперссылка  "Показать ошибки загрузки").
