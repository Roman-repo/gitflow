Обработка "Дерево объектов формата"

Обработка предназначена для удобного визуального представления структуры формата.

Основные возможности:

  • Представление формата в иерархическом виде.
  • Поиск ссылок на объект формата среди других объектов формата, переход по найденным ссылкам (флаг Отображать поиск ссылок).
  • Установка закладок на ветвях дерева с последующим переходом между закладками (кнопки на верхней командной панели).
  • Редактирование структуры формата (опция для продвинутых пользователей)

Редактирование структуры формата

Возможность включается с помощью кнопки Еще - Редактировать структуру формата.

Для изменения существующих объектов, свойств формата достаточно открыть форму соответствующего объекта.

Для добавления новых объектов, свойств формата следует использовать кнопки Добавить либо Копировать. Удобнее всего выбрать наиболее подходящий объект и скопировать его, позднее скорректировав необходимые данные. Сохранить версию формата в файл xsd можно с помощью обработки Выгрузка структуры формата.
