Справочник "Элементы описания"

Содержит информацию о разделах, которые необходимо включить в описание версии формата.

Предусмотрена иерархия элементов справочника, т.е. вышестоящие разделы включают в себя подчиненные разделы.

Наименование содержит пользовательское название элемента и не влияет на содержимое описания объекта формата.

Порядок определяет последовательность элементов описания в пределах раздела.

Вид раздела Заголовок

Предназначен для вывода заголовков разного уровня. Текст заголовка следует указать на закладке Текст описания. Уровень заголовка позволяет выстраивать иерархию заголовков в том числе при формировании оглавления.

Вид раздела Простой текст

Предназначен для вывода обычного текста произвольного содержания

Вид раздела Описание объекта формата

Предназначен для вывода описания указанного объекта формата. Все содержимое в данном случае определяется описанием, указанным непосредственно в объекте формата

  • Заголовок объекта формата соответствует названию объекта формата.
  • Описание объекта формата определяется описанием, указанным в объекте формата. Его можно увидеть на закладке Текст описания. Если изменить описание, оно будет сохранено в Объекте формата.
  • Состав реквизитов и табличных частей, а также их описание берутся из свойств формата, подчиненных объекту формата.

Создание заголовка к элементу описания

Раздел доступен если форма элемента описания открывается из формы Описания, закладка Проверка описания
В этом случае можно к элементу описания создать заголовок в том же окне. Порядок заполнения:
  • Группа элементов описания: место в иерархии, где будет заголовок текущего элемента описания
  • Наименование, Тип элемента, Объект формата, Порядок: значения для текущего элемента описания
  • Текст нового заголовка + Порядок: указать требуемый текст заголовка и порядок его следования внутри элемента, указанного в Группе элементов описания
При записи элемента описания будет автоматически создан элемент описания с типом Заголовок, и в него будет помещен новый элемент описания.
