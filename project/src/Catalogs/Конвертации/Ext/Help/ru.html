Справочник "Конвертации"

Конвертация представляет собой совокупность правил выгрузки / загрузки данных для Релиза 

Предусмотрены два типа конвертаций:

  1. Формат XDTO - с использованием универсального формата EnterpriseData. В этом случае настраиваются правила синхронизации между универсальным форматом и конфигурацией. 
    1. Одна и та же конвертация может использоваться для нескольких версий формата. Поддерживаемые версии формата указываются на закладке Версии формата. 
    2. Если предполагается, что синхронизация данных будет использоваться в решении на платформе 8.2, следует установить соответствующий признак.
    3. Версия формата менеджера обмена: рекомендуется установить значение "2", если версия БСП в конфигурации 2.4.1 или старше.
  2. Формат XML - с использованием формата XML как в Конвертации данных ред.2. В этом случае настраиваются правила синхронизации между двумя конфигурациями.

Сами правила определяются другими объектами метаданных, связанными с конвертацией.

Для удобного распределения конвертаций по типам предусмотрены предопределенные группы конвертаций. При вводе новой конвертации в группу тип конвертации заполняется автоматически.

Можно указать список параметров конвертации, которые будут доступны во всех алгоритмах выгрузки и/или загрузки данных.

Предусмотрены глобальные обработчики, которые выполняются в разные моменты (перед конвертацией, после конвертации и т.д.). Состав обработчиков определяется типом конвертации. Параметры каждого обработчика можно увидеть с помощью подсказки.

Статус - позволяет хранить текущий статус конвертации.

Выгружать модуль в файл / выгружать правила в файл (в зависимости от типа конвертации). Позволяет указать место выгрузки правил по умолчанию.

Настройки для конвертации в формате XDTO

Версии формата: перечень поддерживаемых версий формата

Использовать типизацию переменных: при установке опции в текст модуля будут добавлены дополнительные комментарии, содержащие типы переменных - параметров процедур

Использовать разделение модуля: модуль менеджера будет разбит на несколько частей, в целях уменьшения размеров общего модуля. См. ниже раздел Режим разделения модуля

Режим разделения модуля

Режим предусмотрен для конвертации в формате XDTO. Включается с помощью флага Использовать разделение модуля. Настройки производятся на закладке Модули конвертации.

Способ выгрузки модуля. Указывается в каком виде будут выгружаться модули:

  • Файлы TXT - модули выгружаются в формате текстовых файлов
  • Файлы XML - модули сохраняются в файлы, которые были ранее подготовлены с помощью Выгрузки конфигурации в файлы. Далее эти модули могут быть загружены обратно в конфигурацию через загрузку конфигурации из файлов.

Выгружать модули в каталог: место выгрузки модуля в зависимости от способа выгрузки. Либо каталог с текстовыми файлами, либо каталог куда выгружены файлы конфигурации

Список модулей

Содержит модули конвертации. При включении опции разделения модуля автоматически создаются предопределенные модули

  • Базисный - модуль для взаимодействия с подсистемой обмена данными
  • Алгоритмы - модуль содержащий алгоритмы
  • Документы (отправка) - модуль, содержащий правила предназначенные для отправки документов. Если правило одновременно для отправки и получения, оно тоже попадает в модуль отправки.
  • Документы (получение) - модуль, содержащий правила предназначенные для получения документов.
  • Прочее: справочники, ПВХ и т.д. (отправка) - модуль, содержащий правила предназначенные для отправки других объектов (кроме документов). Если правило одновременно для отправки и получения, оно тоже попадает в модуль отправки.
  • Прочее: справочники, ПВХ и т.д. (получение) - модуль, содержащий правила предназначенные для получения других объектов (кроме документов). Если правило одновременно для отправки и получения, оно тоже попадает в модуль отправки.

Состав предопределенных модулей нельзя изменить. Можно изменить только имена модулей.

Если не менять настройку правил конвертации, правила автоматически распределяются между предопределенными модулями в зависимости от направления обмена и типа объекта метаданных.

Пользовательские модули

В список модулей можно добавить Пользовательские модули. Эти модули позволят более мелко разбить правила между разными общими модулями. 

Чтобы привязать правило к Пользовательскому модулю, необходимо указать ссылку на Пользовательский модуль в правиле обработки данных, в правиле конвертации объекта либо в алгоритме.

Выгрузка в модуль менеджера объекта метаданных

В правилах конвертации есть возможность указать что правила выгружаются в модуль менеджера объекта метаданных.

При выгрузке в файлы TXT для каждого объекта метаданных будет создан отдельный файл с частью модуля, содержащего логику для обменов через универсальный формат. Эту логику необходимо встроить в модуль менеджера самостоятельно.

При выгрузке в файлы XML процедуры для синхронизации данных будут встроены в модуль менеджера в предопределенную область СлужебныеПроцедурыИФункции -> ОбменДанными_СинхронизацияДанныхЧерезУниверсальныйФормат

Внимание! Использование модуля менеджера объекта для хранения правил усложняет кастомизацию приложений.

Дерево модулей

Список модулей можно переключить в режим дерева. В этом случае добавлять новые модули нельзя. Режим дерева предназначен для просмотра информации какие правила к какому модулю будут относиться.

Возможности для конвертации с выгрузкой в файлы XML

Параметры подключения: по гиперссылке открывается форма с параметрами подключения к информационной базе

Выгрузить конфигурацию в файлы (кнопка желтая папка со стрелкой вверх): конфигурация с заданными параметрами подключения будет выгружена в каталог, указанный в поле Выгружать модули в каталог

Загрузить конфигурацию из файлов (кнопка желтая папка со стрелкой вниз): из каталога, указанного в поле Выгружать модули в каталог файлы конфигурации будут загружены в информационную базу с заданными параметрами подключения. Для обновления конфигурации базы данных после загрузки потребуется зайти в конфигуратор.

Выгрузить конвертацию в файлы (кнопка со стрелкой вверх): конвертация будет сохранена в файлы, полученные выгрузкой конфигурации (см. выше)

Загрузить конвертацию (кнопка со стрелкой вниз): правила конвертации будут созданы / обновлены из модулей конфигурации, расположенных в указанном каталоге

Удалить правила из модулей менеджера (кнопка с крестом): будут обработаны все модули менеджера объектов, из них будут удалены области с правилами конвертации

Особенности загрузки конвертации при использовании режима разделения модуля

Для конвертации должны быть созданы все модули (предопределенные и дополнительные). 

Наименования модулей должны соответствовать названиям общих модулей в конфигурации, из которой происходит загрузка правил.
