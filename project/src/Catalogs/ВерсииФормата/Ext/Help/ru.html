Справочник "Версии формата"

Справочник содержит перечень версий формата, которые используются при настройке правил обмена. Данному справочнику подчинено большое количество дополнительных справочников, хранящих содержимое формата.

Для версии должно быть указано Пространство имен: в соответствии с тем, которое указано для схемы XDTO в конфигурациях, поддерживающих данную версию формата. Например, http://v8.1c.ru/edi/edi_stnd/EnterpriseData/1.7

Стандартные версии формата должны располагаться в предопределенной группе Enterprise Data

Версии формата заполняются с помощью обработки Загрузка структуры формата. Загрузка производится из файлов xsd.

Расширение версии формата

Расширения формата должны располагаться в отдельных папках. Имя папки должно соответствовать пространству имен расширения (например, http://1cbn.ru/edi/ed/ru). Для версии, которая является расширением, должен быть установлен флаг Расширение.

Взаимосвязи между основной версией и расширением настраиваются в регистре сведений Взаимосвязи версий формата и расширений. 

В случае использования расширения, при настройке правил список объектов, свойств, значений основного формата дополняются содержимым расширения.

Редактирование формата

Если есть необходимость внесения изменений в структуру формата, рекомендуется использовать обработку Дерево объектов формата , включив в ней возможность Редактировать структуру формата (кнопка Еще).

Сохранить версию формата в файл xsd можно с помощью обработки Выгрузка структуры формата.
