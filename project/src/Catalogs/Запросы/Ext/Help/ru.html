Запросы

Содержит запросы, подчиненные конвертации. Используются только для конвертации XML.
Каждая позиция описывает текст запроса, который может многократно выполняться с различными параметрами в любых обработчиках событий выгрузки и загрузки данных в правилах обмена. Если запрос используется в обработчиках событий загрузки данных, то в форме настройки запроса необходимо установить признак "Используется при загрузке".

Пример вызова запроса:

Запросы.<ИмяЗапроса>.УстановитьПараметр(<Имя>, <Значение>);

РезультатЗапроса = Запросы.<ИмяЗапроса>.Выполнить();
