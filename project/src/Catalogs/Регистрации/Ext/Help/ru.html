Справочник "Регистрации"

Служит для объединения  правил регистрации объектов, привязанных к указанной конфигурации и плану обмена.
Если у регистрации есть подчиненные правила регистрации, реквизит Конфигурация не доступен для изменения.
Для создания правил регистрации в новой конфигурации следует создавать новую регистрацию через загрузку правил регистрации.

Варианты выгрузки правил

  • В файл XML - правила сохраняются в xml файл
  • В общий модуль - правила сохраняются в виде текстового модуля, который сохраняется в буфер обмена
Полученные правила используются в прикладной конфигурации

Дочерние конфигурации

Указываются конфигурации, которые являются дочерними по отношению к основной и могут использовать то же подмножество правил регистрации.
Доступны для выбора при сохранении правил регистрации в общий модуль.
Для каждой конфигурации указывается строковый тэг, который будет использоваться для обрамления исключаемых участков кода модуля регистрации.
