Справочник "Релизы"

Содержит сведения о релизах конфигураций, для которых может производиться настройка правил обмена. 

Для каждого релиза может быть указана связанная с ним Конфигурация, через которую осуществляется связь с релизами других конфигураций. Если взаимосвязь не требуется, можно указать предопределенную конфигурацию из списка.

Далее в формах правил и в конвертациях там где выбирается поле "Конфигурация" - на самом деле выбирается Релиз конфигурации.

Имеет в подчинении справочник Объекты метаданных.

Обновление структуры метаданных по расписанию

Предусмотрена возможность настроить автоматическое обновление с помощью регламентного задания. 

Загрузка производится из файлов XML или EDT (подробнее см. настройки обработки Загрузка структуры метаданных из файлов XML).
