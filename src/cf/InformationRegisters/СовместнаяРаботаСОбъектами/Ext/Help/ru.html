Регистр сведений "Совместная работа с объектами"

Предназначен для хранения сведений, необходимых для работы функционала совместной работы над правилами.
  • Объект - ссылка на правило
  • Действие - действие с объектом
  • Пользователь - инициатор действия
  • Рабочая копия - копия правила на момент захвата
