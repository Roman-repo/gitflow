Обработка "Выгрузка модуля"

Предназначена для подготовки модуля менеджера обмена через универсальный формат.

Необходимо указать конвертацию, для которой будет подготовлен модуль.

Если в информационной базе используется режим совместной работы, возможны два способа выгрузки модуля:

  • На текущий момент. Правила, захваченные текущим пользователем, выгружаются в измененном виде. Правила, захваченные другими пользователями, выгружаются по состоянию на момент захвата
  • По состоянию хранилища. Все захваченные правила выгружаются по состоянию на момент захвата. Внесенные и не помещенные в хранилище изменения не выгружаются.
