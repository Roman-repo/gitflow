Обработка Автогенерация правил конвертации XML

Предназначена для автоматического создания правил конвертации в формате XML между указанными релизами конфигураций.
В форме следует выбрать
  • Конфигурацию источник
  • Конфигурацию приемник
  • План обмена
  • Способ загрузки (новая / существующая конвертация)
  • Конвертацию - при условии загрузки правил в существующую конвертацию
Состав объектов метаданных, для которых создаются правила, определяется составом плана обмена.
Сопоставление объектов метаданных и свойств производится по их идентификаторам, поэтому метаданные должны быть загружены с помощью обработки Загрузка структуры метаданных из файлов XML
При необходимости создаются правила конвертации объектов и правила конвертации предопределенных данных для конвертации свойств ссылочного типа.
