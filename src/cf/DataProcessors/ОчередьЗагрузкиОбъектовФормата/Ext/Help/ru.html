Обработка Очередь загрузки объектов формата

Обработка предназначена для построения очереди загрузки объектов формата на основании связей между объектами.
При начале работы с обработкой необходимо указать версию формата.

Предварительный анализ

Этап предварительного анализа нужен для того, чтобы выявить перекрестные ссылки на объекты формата и настроить для них порядок загрузки.
После нажатия кнопки "Выполнить анализ" текстовое поле Перекрестные ссылки будет заполнено объектами, в которых есть перекрестные ссылки друг на друга.
По результатам этого анализа необходимо заполнить ручной порядок загрузки для найденных перекрестных ссылок.

Указание ручного порядка загрузки для перекрестных ссылок

Если в объектах формата есть перекрестные ссылки, они могут мешать построению очереди загрузки. Чтобы этого не происходило, следует вручную описать порядок загрузки таких объектов.
Для этого предназначено табличное поле "Ручной порядок загрузки перекрестных ссылок" на закладке "Предварительный анализ".
  • В колонке "Ведущий объект" необходимо указать объект формата, который будет загружен в первую очередь.
  • В колонке "Ведомый объект" необходимо указать объект формата, который зациклен с ведущим и будет загружен во вторую очередь.
Например, если есть циклическая ссылка "Номенклатура - Спецификация", в строке следует указать "Справочник.Номенклатура" и "Справочник.СпецификацииНоменклатуры".
Настроенный ручной порядок загрузки можно сохранить в файл (кнопка Сохранить настройки перекрестных ссылок) и использовать позднее при последующей работе с обработкой (кнопка Восстановить настройки перекрестных ссылок).
После того как заполнен ручной порядок загрузки перекрестных ссылок можно переходить на закладку Формирование экспортного метода.

Формирование экспортного метода

После нажатия кнопки Сформировать будут выполнены следующие действия:
  • Табличное поле будет заполнено сведениями о порядке загрузки объектов формата
  • В текстовом поле будет автоматически сформирован текст процедуры с экспортным методом, заполняющим очередь загрузки объектов формата
  • Если не все объекты формата удалось распределить в очередь, перед текстом процедуры будет выведен соответствующий комментарий (какие именно объекты формата не обработаны)
Текст процедуры можно сохранить в файл с помощью кнопки Сохранить экспортный метод.
