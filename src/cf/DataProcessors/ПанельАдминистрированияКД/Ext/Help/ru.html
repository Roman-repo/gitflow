Используемый функционал

Использовать формат XDTO

Опция позволяет выполнять настройку правил конвертации с использованием формата Enterprise Data. Если данная возможность включена, при создании  Конвертации  можно выбрать тип Формат XDTO.
См. также  Версии формата 

Использовать формат XML

Опция позволяет выполнять настройку правил конвертации между Конфигурациями  с использованием формата XML - так же, как это было возможно в конфигурации Конвертация данных ред.2

Использовать правила регистрации объектов

Опция позволяет настраивать Правила регистрации объектов

Проектирование формата

Вести учет Требований  к функциональности формата, проектных решений. Составлять описания версий формата, отчет по сравнению версий формата.

Совместная работа

Опция позволяет организовать совместную работу пользователей с правилами конвертации и регистрации. Если опция включена, то работа ведется по следующим правилам:
  • Для редактирования правила пользователь должен правило захватить (кнопка Захватить объект в форме правила)
  • После окончания работы измененное правило может быть помещено в хранилище (кнопка Снять захват объекта -> вариант Снять захват с записью объекта)
  • Есть возможность вернуться к версии правила до захвата, отменив внесенные изменения (кнопка Снять захват объекта -> вариант Отменить захват с откатом изменений)
  • Правила конвертации и правила регистрации можно выгрузить в модуль менеджера / в файл xml в двух вариантах
    • На текущий момент (в результат попадают по захваченным пользователем объектам - все внесенные изменения, по не захваченным объектам - то что находится в хранилище)
    • По состоянию хранилища (изменения, не помещенные в хранилище, в результат не попадают)
