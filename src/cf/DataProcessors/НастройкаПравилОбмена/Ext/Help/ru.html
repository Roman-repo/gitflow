Режим совместной работы над правилами

Включение режима производится в меню Администрирование - Используемый функционал, флаг Совместная работа.
Опция совместной работы накладывает ограничения на разработку следующих объектов:
  • Правила конвертации объектов и связанные с ним правила конвертации свойств
  • Правила конвертации предопределенных данных
  • Правила обработки данных
  • Алгоритмы
  • Запросы

Разработка правил в режиме совместной работы

При разработке правил действуют следующие ограничения:
  1. Пользователь может вносить изменения в объект только после его захвата
  2. При создании нового объекта он автоматически захватывается текущим пользователем
  3. Пока объект захвачен, другие пользователи видят версию объекта на момент захвата
  4. После окончания работы над объектом пользователь должен выполнить отмену захвата
  • либо с сохранением изменений, изменения станут видны всем пользователям
  • либо с откатом изменений, при этом восстанавливается версия объекта до захвата

Выгрузка правил в режиме совместной работы

Существуют две возможности выгрузки правил конвертации в модуль менеджера / в файл xml:

Выполнить выгрузку на текущий момент

Изменения, внесенные текущим пользователем но не помещенные в хранилище, выгружаются как есть.
Все остальные объекты выгружаются по состоянию хранилища, т.е. без учета изменений

Выполнить выгрузку по состоянию хранилища

Все объекты выгружаются по состоянию хранилища, изменения в захваченных но не помещенных в хранилище объектах не учитываются
