Обработка "Загрузка регистрации"

Обработка предназначена для загрузки правил регистрации из XML файла либо из общего модуля.

Загрузка правил в новую регистрацию

Для загрузки правил в новую регистрацию на этапе "Выбрать регистрацию для загрузки" следует указать вариант "Новая". При необходимости можно заполнить название новой регистрации.

Конфигурация при этом может быть выбрана существующая, либо указан вариант загрузки "Новая конфигурация".

Если указана существующая конфигурация, можно обновить ее установив флаг "Обновлять метаданные существующей конфигурации".

Загрузка правил в существующую регистрацию

Для загрузки правил в существующую регистрацию на этапе "Выбрать регистрацию для загрузки" следует указать вариант "Существующая", и указать обновляемую регистрацию.

Настройка источника загрузки

После выбора загружаемой регистрации следует шаг "Настроить источник загрузки".

Если на этапе выбора регистрации был указан вариант загрузки конфигурации "Новая регистрация" и "Новая конфигурация", доступны следующие источники загрузки:

  • Выгрузка конфигурации в файлы XML. Следует указать путь к каталогу, в который были выгружены файлы из Конфигуратора (меню Выгрузить конфигурацию в файлы)
  • База EDT. Следует указать файл project базы, развернутой в среде 1С-EDT
Если выбран один из этих двух источников загрузки, следует также указать имя общего модуля, в котором содержатся правила регистрации.

Если на этапе выбора регистрации был указан вариант загрузки "Существующая конфигурация" и не установлен флаг обновления метаданных, помимо перечисленных выше источников добавляются следующие варианты:
  • Текстовый файл. Следует указать расположение текстового файла, в который сохранен общий модуль с правилами регистрации
  • Файл XML. Следует указать расположение файла XML, в который сохранен макет с правилами регистрации

Загрузка правил регистрации

После настройки источника загрузки следует нажать на гиперссылку "Загрузить правила регистрации".
При этом будет выполнена загрузка структуры метаданных (если это было указано) и загрузка правил регистрации.
Если при загрузке возникали ошибки, их можно увидеть по гиперссылке "Показать ошибки загрузки".

Загрузка правил при использовании совместной работы

Если в информационной базе включен режим совместной работы, при загрузке правил применяются следующие ограничения:
Обновляются правила, которые не захвачены либо захвачены текущим пользователем запустившим загрузку
Если загружаемое правило захвачено другим пользователем, оно не может быть обновлено. О наличии таких правил будут выведены ошибки (гиперссылка  "Показать ошибки загрузки").
