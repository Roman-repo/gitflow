Обработка "Проверка конвертации"

Предназначена для выявления ошибок в правилах конвертации.
Доступны разные типы проверок в зависимости от типа конвертации.

Для конвертации типа XML

Группа проверок "Проверка типов источника и приемника в ПКС"

Обнаруживает правила конвертации свойств, в которых явно указано ПКО и при этом тип источника / приемника является множественным

Для любых конвертаций

Проверка источника и приемника правил

Обнаруживает правила, в качестве источника / приемника в которых указан удаленный объект конфигурации.

Проверка состава плана обмена и подписок на событие

Обнаруживает правила обработки данных, в которых объект данных не включен в план обмена либо в подписки на события.
Для выполнения этих проверок потребуется выбрать план обмена, по которому происходит синхронизация.
