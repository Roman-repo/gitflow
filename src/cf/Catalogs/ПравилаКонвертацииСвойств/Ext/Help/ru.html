Правила конвертации свойств

Правила конвертации свойств подчинены  Правилу конвертации объектов
Иерархическая структура правил позволяет настраивать правила конвертации для табличных частей. Сама табличная часть должна соответствовать группе правил конвертации свойств, подчиненные группе элементы соответствуют реквизитам табличной части.
Правила конвертации реквизитов шапки располагаются на верхнем уровне иерархии.
Для свойств ссылочных типов следует указать Правило конвертации, в соответствии с которым должно происходить преобразование свойства.

Конвертация XDTO

В зависимости от области применения правила конвертации объекта правило описывает порядок заполнения свойства при отправке и/или при получении данных.
Используется алгоритм конвертации: заполнение значения свойства выполняется в алгоритме правила конвертации, которому принадлежит правило конвертации свойства.
Для правил конвертации свойств в формате xdto обработчики событий не предусмотрены. Вся необходимая логика должна располагаться в обработчиках владельца - правила конвертации объекта.

Конвертация XML

Правило описывает порядок формирования свойства объекта-приемника.
В качестве источника данных может выступать свойство объекта-источника, или произвольные данные. 
Получить значение из входящих данных: конвертируемое значение будет получено не из объекта-источника, а из параметра ВходящиеДанные (данный параметр следует инициализировать в обработчиках событий правила конвертации объекта, к которому принадлежит правило конвертации свойства).

Поиск объекта при загрузке по свойству: свойство является синхронизирующим, то есть по данному свойству будет выполнятся поиск существующих объектов информационной базы при загрузке данных. 

Передавать данные в параметр: получателем значения является не свойство объекта, а параметр, который будет интерпретирован в обработчиках на стороне загрузки данных.

Не замещать значение данного свойства у существующих объектов в приемнике:для существующих объектов информационной базы, т.е.идентифицированных при загрузке, данное свойство переустанавливаться не будет.

Обработчики событий

Перед выгрузкой - выполняется перед выгрузкой значения свойства. Возможен отказ от  выгрузки
При выгрузке - выполняется при начале выгрузки свойства.
После выгрузки - выполняется после выгрузки свойства
Перед обработкой - выполняется перед обработкой группы свойств, например, перед  выгрузкой табличной части. Возможен отказ от выгрузки. Можно определить  произвольную коллекцию, являющуюся источником данных.
После обработки - выполняется после обработки группы свойств (например, после выгрузки  табличной части или набора движений регистра).  Возможен Отказ от записи в файл  узла коллекции объектов.
