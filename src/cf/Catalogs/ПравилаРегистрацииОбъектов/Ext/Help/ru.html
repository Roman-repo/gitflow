Справочник "Правила регистрации объектов"

Правила регистрации объектов предназначены для описания ограничений миграции данных на узлах планов обмена.
Объект настройки: объект метаданных, для которых настраивается ограничение. Например, Справочник.Контрагенты. Можно выбрать только те объекты, которые входят в состав плана обмена, указанного в Регистрации 
Переключатель режима: реквизит плана обмена, который используется для переключения режима выгрузки объектов текущего правила регистрации. Например, "Режим выгрузки справочников" или "Режим выгрузки документов". Если не указать, то переключение режима выгрузки будет не доступно.

Отбор по свойствам плана обмена

Сопоставление реквизитов объекта с реквизитами плана обмена и сопоставление реквизитов плана обмена со значениями примитивного типа. Допускается обращение к реквизитам табличной части плана обмена (через точку).
Правила отбора могут быть объединены в группы И или ИЛИ. Элементы отбора корневой группы сопоставляются по И.

Отбор по свойствам объекта

Сопоставление реквизитов объекта с произвольными значениями. В качестве свойств объекта могут быть использованы только реквизиты шапки.
Правила отбора могут быть объединены в группы И или ИЛИ. Элементы отбора корневой группы сопоставляются по И.

Обработчики событий

Обработчики позволяют задать ограничения, которые не поддерживаются функционалом отборов по свойствам объекта либо по свойствам плана обмена.
Перед обработкой - выполняется перед применением правила регистрации, в момент, когда  запрос к информационной базе для определения узлов-получателей еще не  выполнен.
При обработке - выполняется перед выполнением запроса к информационной базе для определения  узлов-получателей, в момент, когда текст запроса сформирован и получены значения  свойств объекта. Параметры запроса инициализированы значениями из текущей версии  объекта.
При обработке (доп) - выполняется перед выполнением запроса к информационной базе для определения  узлов-получателей, в момент, когда текст запроса сформирован и получены значения  свойств объекта. Параметры запроса инициализированы значениями из версии объекта  до изменения. Обработчик не выполняется для новых объектов и не выполняется в  процессе выгрузки данных.
После обработки - выполняется после  выполнения запроса к информационной базе, когда определен список  узлов-получателей. Список узлов-получателей сформирован, но не применен к  объекту. Можно очистить или дополнить список узлов-получателей.

Копирование правила регистрации на другие объекты

Позволяет распространить текущее правило регистрации на другие объекты метаданных, входящие в план обмена но еще не имеющие правила регистрации.
Действие выполняется с помощью кнопки Копировать на другие объекты. В открывшейся форме выбрать подходящие объекты метаданных.
При этом создаются новые правила регистрации. В них из текущего правила копируются обработчики, отборы по свойствам объекта и отборы по свойствам плана обмена.

Правила регистрации для иерархических справочников

В общем случае для элементов и для групп справочника должны быть созданы два разных правила регистрации. Обусловлено это как прикладным смыслом, так и техническим – состав реквизитов элементов и групп справочника в общем случае различный.
В правиле, которое будет использоваться для регистрации элементов справочника, в обработчике правила Перед обработкой следует написать: 
Отказ = Объект.ЭтоГруппа;
Условия регистрации в соответствии с требующейся логикой фильтрации элементов справочника.
В правиле для регистрации групп справочника в обработчике правила Перед обработкой следует написать:
Отказ = Не Объект.ЭтоГруппа;
Условия регистрации оставим пустыми – это позволит регистрировать все группы справочника.
