Справочник "Алгоритмы"

Произвольные алгоритмы, которые могут использоваться в любых обработчиках выгрузки и загрузки данных.

В правилах конвертации XML для вызова алгоритма следует использовать конструкцию Выполнить(Алгоритмы.<ИмяАлгоритма>);

В правилах конвертации XDTO вызов алгоритма осуществляется аналогично вызову любой процедуры или функции в текстах модулей: <ИмяАлгоритма>(<ПараметрыАлгоритма>).

Конвертации - перечень конвертаций, в состав которых входит алгоритм. При создании нового алгоритма он входит в состав одной конвертации, в диалоге которой он создан. Для добавления алгоритма в другие конвертации следует использовать кнопку Добавить элемент в состав конвертации. Если конвертаций несколько и необходимо убрать алгоритм из некоторых конвертаций, следует использовать кнопку Выделить элемент из состава конвертаций. 

Используется при загрузке. Признак виден, если алгоритм принадлежит конвертации XML. Означает, что данный алгоритм вызывается при загрузке данных.

Функция. Признак виден, если алгоритм принадлежит конвертации XDTO. Означает, что данный алгоритм является функцией и имеет возвращаемое значение.

Экспортный. Признак виден, если алгоритм принадлежит конвертации XDTO. Означает, что данный алгоритм может вызываться вне модуля синхронизации данных через универсальный формат.

Пользовательский модуль. Модуль, в который будет выгружен алгоритм. Заполняется в режиме разделения модуля.
