Справочник "Описания"

Предназначен для подготовки описания версии формата в виде документа html.

Структура документа определяется подчиненным справочником Элементы описания.

Вывод описания

Вывод описания производится на закладке Результат.

При нажатии на кнопку "Показать результат" текст описания будет выведен в поле HTML документа на форме. Для сохранения полученного результата в файл необходимо использовать кнопку "Сохранить в файл".

Проверка описания

Данная закладка содержит инструмент для проверки описания. После нажатия на кнопку Выполнить проверку будет заполнена таблица потенциальных проблемных ситуаций.

Проблема: Объект без описания

У объекта формата нет соответствующего ему элемента описания. По двойному щелчку на строке открывается форма нового Элемента описания, в которой можно заполнить элемент описания объекта формата и разместить его в иерархии других элементов описания.

Проблема: Заголовок без содержимого

У объекта описания с типом "Заголовок" нет вложенных элементов описания. Такая ситуация может возникнуть при копировании описания, если объект формата был удален либо переименован.

По двойному щелчку на строке открывается форма списка Элементов описания с позиционированием на проблемном заголовке. 

Проблема: Описание объекта без отдельного заголовка

У элемента описания объекта формата нет собственного заголовка. Эта ситуация не всегда является ошибкой. например Общие табличные части и Группы общих свойств выводятся в описание с одним общим заголовком.

При необходимости можно открыть форму данного Элемента описания и создать к нему заголовок.

Скрытые строки в списке проблем

Если ситуация не является ошибкой, можно скрыть эту строку из списка через дополнительное меню "Еще - Скрыть из списка".
Для того чтобы показать скрытые строки, необходимо нажать на "Еще - Показать скрытые в списке".
Для того чтобы отменить скрытие проблемы, необходимо сначала показать скрытые в списке, потом встать на нужную строку и нажать "Еще - Показать скрытые"
